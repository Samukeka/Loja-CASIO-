⌚ Loja Casio/G-Shock

Um projeto em Spring Boot + Thymeleaf + H2 Database, representando uma loja virtual de relógios Casio/G-Shock com um design diferenciado, minimalista e elegante.
Inspirado em conceitos de UX/UI asiáticos (limpeza visual, tipografia clara e foco no produto).

🚀 Tecnologias Utilizadas

Java 17+

Spring Boot (Web, Data JPA, Validation)

Thymeleaf (renderização server-side)

H2 Database (banco em memória para desenvolvimento/testes)

Lombok (redução de boilerplate no Java)

📌 Funcionalidades

✔️ Listagem de relógios (Casio/G-Shock)
✔️ Visualização de detalhes do produto
✔️ Carrinho de compras (simples, sessão do usuário)
✔️ CRUD de produtos (apenas para admin)
✔️ Banco H2 integrado, com dados de exemplo (seed)
✔️ Layout responsivo e elegante com Thymeleaf + CSS
